# Notebook

Open 01_scania_aps_end_to_end.ipynb using the Python 3.12 environment installed
with requirements.txt, requirements-dev.txt and requirements-notebook.txt.
Run All executes shared project modules; leave these modules at the repo root.

Default settings rebuild training and development experiments into a fresh
ignored runs/ directory, then verify the results. Set both REBUILD flags to
False for a quick walkthrough of the shipped release. The approved artifacts/
directory is never overwritten. See docs/PROJECT_GUIDE.md for migration and
the full explanation of notebook changes.
